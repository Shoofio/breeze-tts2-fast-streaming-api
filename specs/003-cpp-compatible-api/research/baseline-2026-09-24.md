# Performance baseline: 2026-09-24 (T002, SC-007)

The pre-change baseline that every later benchmark in this feature is compared against.

## Setup

- **GPU**: NVIDIA GeForce RTX 4090 (driver 596.36), WSL2.
- **Server code**: the API from `2218c39` (the unchanged `breeze_infer/api.py` at the start of
  this feature). The commits after it, up to `70f7b98`, only add dependency pins, the benchmark and
  the live harness.
- **Benchmark**: `breeze_infer/bench_api.py` at `70f7b98`.
- **Server command**:
  `.venv/bin/python -m breeze_infer.api <Breeze-TTS-2 snapshot c1c8ca18> --port 7860 --fast-all`
- **Benchmark command**:
  `.venv/bin/python -m breeze_infer.bench_api --api old --url http://127.0.0.1:7860 --runs 3`
- Every case gets one warm-up request before its timed runs.

## Notes for later comparisons

- **The design cases are noisy.** A 3-run median can move by more than 10% between two runs of the
  same server: medium_design's TTFA median was 223 ms over 3 runs and 75 ms over 10. RTF is
  stable, within about 5%. Later comparisons (T043, T054, T082) should also run 10 runs, and
  should treat a TTFA regression over 10% as real only when it shows in the 10-run median too.
- **medium_design is split differently on the new API.** The passage is 428 characters, so
  on the new API it becomes two pieces: the first under the 200-character opening budget, and the
  second anchored on the first. The old API generates it as one piece. TTFA should improve, since
  the first piece is shorter. RTF includes a second prefill.
- **short_voice has no baseline.** The old API has no voices route.
