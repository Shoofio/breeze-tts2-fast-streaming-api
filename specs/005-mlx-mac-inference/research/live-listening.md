# Listening test (T033, SC-005): 2026-10-04

**SC-005:** every Mac output is intelligible and free of artifacts, and matches the CUDA output's
speaker (clone, direction) or description (design).

**Prompt set:** 10 fixed prompts, defined in `listening/make_set.py`. Every backend gets
identical requests: GET `.wav`, seed 42.
- Clone and direction use the saved voices `Eric01` and `Vale01`, which exist on both machines.
- Design and direction use `cfg_scale` 4.

```bash
python3 specs/005-mlx-mac-inference/research/listening/make_set.py --url http://127.0.0.1:8080 --out <dir>
```

**Generated:**
- **Mac 8-bit and Mac bf16:** by the main session, against `scripts/start_breeze_mac.sh` at
  2.2.0, with the voices folder holding `Eric01`/`Vale01`. The WAVs are in the session scratchpad
  (`listening/mac-8bit/`, `listening/mac-bf16/`).
- **CUDA:** to be generated by running the same script against `scripts/start_breeze.sh` on the
  CUDA machine.

Seeds don't reproduce across backends, because their numerics and random streams differ. The
comparison is of speaker and style, not of identical audio.
